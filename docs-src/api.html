API reference

Every export, by entry point. The build fails if this page names anything romp doesn't export.

romp/core

Stage

One planck.js world, baked once.

new Stage({ pxPerMetre?: 100, gravity?: 9.81 * 2.2, yDown?: true })
stage.ground(points, { friction?, layer? }): PlanckBody
stage.add(actor): actor                  // sets actor.stage, then actor.build(stage)
stage.bake({ frames? | duration?, fps?: 30, hz?: 240 }): Stage
stage.pose(t, { discrete? }): void      // calls each actor's apply(pose, t); NaN poses arrive as { shown: false }
stage.get<A>(id): A
stage.m(px) · stage.px(metres) · stage.v(x, y)

LAYER

Collision layer bits: FLOOR, A, B, C, D. Give a body a layer and the mask of layers it touches.

Body

A rigid body that records its impacts.

new Body({ id, x, y, w, h, shape?: "rounded" | "box" | "circle", spawn?, vx?, vy?, spin?,
           restitution?, friction?, density?, upright?, angularDamping?, layer?, mask?, bullet?, gravityScale? })
body.impacts: { frame, t, speed, vx, side? }[]     body.landed: number (first landing frame; side hits don't count)

SpringyBody

Welds itself to ground where it first lands on it, so it can be knocked over and wobble back.

new SpringyBody({ ...BodyOptions, ground: PlanckBody, groundY: number, hz?: 2, damping?: 0.18 })
springy.isWelded: boolean

Drop

A dropped prop that stays upright. Contact arrests everything: spin, tilt and depth drift reach rest exactly at touchdown.

new Drop({ ...BodyOptions, foot?, ledge?: { x0, x1, y }, frame?: { x, y }, spinAt?, tilt?, z?: [from, to], rock?: 1 | -1 })
drop.flight(frame): { u, spin, tilt, z, rockDir }      // pair rockDir with rock() for the rock about its tip
drop.framePose(frame, { discrete? }): BodyPose          // the pose minus `frame`, in its parent's coordinates

Leap

A ballistic leap through a surface line; records each crossing with its velocity.

new Leap({ id, x, y, vx, vy, surface, size?, spawn?, gravity?: 1, frame?: { x, y } })
leap.crossings: { frame, t, x, out, vx, vy }[]      pose: { shown, x, y, angle, heading, speed }

poseAt(actor, frame, { discrete?: "nearest" | "previous" }): Pose

Interpolated between baked frames: numbers lerp; booleans and strings switch at the halfway point ("nearest") or hold the earlier frame ("previous").

syllables · talk · talkPose · speechLength

syllables(text, { rate = 8, seed?, fit?, pause = 0.16, gap = 0.03 }?): Syllable[]   // { t0, t1, vowel: "a"|"e"|"i"|"o"|"u"|"m", stress, text }
talk(t, syllables, { lead = 2/30, closed = 2/30 }?): { open: 0..1, vowel, mouth: "closed"|"open"|"wide"|"round", talking, beat }
talkPose(frame, t, syllables, seed?, talkOptions?): CharacterPose & { speech }      speechLength(syllables): seconds

Words as timed syllables (English by vowel group, Chinese, Japanese and Korean by character), and the mouth for each moment. Pass the same list to babble(t, dur, out, { syllables }) and the voice says what the mouth shows.

gaze

gaze(frame, { keys?: { at, x, y?, pursue? }[], seed?, wander = 0.18, saccade = 3, follow = 0.3, delay = 2 }?): { x, y, head, blink, dip }

Eyes that jump to a look in a few frames and hold it (with small drifts), blink on a big change, and a head that follows a couple of frames behind.

jump · react · alive · blinks · keepVolume

jump(frame, at, { height = 120, air = 16, crouch = 5, weight = 0.4, seed? }?): { y, pose, contact, phase }
waddle(frame, { from = 0, period = 20, angle = 10, bob = 0.03, seed? }?): { angle (° about the feet), y (share of height), pose }
react(frame, at, "surprise" | "doubleTake" | "realize" | "tremble" | "giggle" | "nod" | "shake", { seed?, strength? }?): { y (share of height), pose, mouth?, lookX?, contact, done }
takeCurve(dt, { antic = 6, anticDepth = 0.35, accent = "hard", pop?, hold?, settle = 9, settleLevel = 0.5, keep = 8, release = 10 }?): { v, phase, pop }
takeLength(options?): frames
alive(frame, seed?): CharacterPose      blinks(frame, seed?, { perMinute = 14 }?): 0..1      keepVolume(squashY, k = 0.7): squashX
BLINK, LONG_BLINK: blink shapes frame by frame (close fast, open slowly)
REACTION_FRAMES: Record<Reaction, number>      hash01(a, b?): [0, 1)

A jump with its crouch, a speed-stretched parabola and a landing sized by the fall; reactions with their anticipations; idle that breathes unevenly and blinks irregularly; squash that keeps the body's volume.

ease · spring · ringOut · stagger · SPRING · lerp · span · clamp01

Closed-form curves: ease.out, ease.in, ease.inOut; spring(elapsed, SPRING.smooth), ringOut(elapsed, SPRING.bouncy), stagger(t0, i, frames = 3, fps = 30).

Clock

new Clock({ seek, duration, loop?, audio?, onPlay?(t), onStop?() })
clock.play(from?) · clock.pause() · clock.seek(t) · clock.t · clock.playing

Drives seek(t) on requestAnimationFrame; follows audio.currentTime while it's running.

romp/check

analyze

analyze(frames: { f, row: Record<name, Sample> }[], { fps?, width?, height?, whips?, covered?, impacts?, seamless?,
        croppedFraction?: 0.25, croppedSeconds?: 0.5, allowCrop?: string[], lostSeconds?: 1, allowExit?: string[], strobePx?, teleportPx?, jumpPx?, screenCroppedFraction?: 0.01,
        // the text rules
        scenes?: seconds[], strict?: false, safe?: share | { top, right, bottom, left }, offsafeSeconds?: 0.1,
        coversFraction?: 0.05, coversSeconds?: 0.1, overlapFraction?: 0.02, overlapSeconds?: 0.2, propOverlapSeconds?: 0.04,
        emptySeconds?: 0.2, headingSeconds?: 0.5, reading?: { wpm?: 180, min?: 1.5 }, stale?: boolean | seconds,
        // screens and anchors
        legiblePx?: 20 at a 1080 short side, minTextPx?: 16, textPx?: legiblePx, legibleSeconds?: 0.5, anchorPx?: 10% of the short side, anchorSeconds?: 0.1, groundPx?: 2,
        // the frame as a whole
        blankSeconds?: 0.5 | false, clippedFraction?: 0.01, clippedSeconds?: 0.5, occupancy?: boolean | share | { share?: 0.2, seconds?: 2 },
        layoutOnly?: false,     // sampled frames: the layout rules only
        allow?: { offsafe?, covers?, overlap?, unfinished?, unread?, empty?, stale?, legibility?, anchor?, clipped?, blank?, occupancy?: string[] } }): Report
Sample = { x, y, shown, onScreen, area, opacity, impact?, seamless?, box?: { x0, y0, x1, y1 }, allowCrop?: boolean | share, allowExit?,
           role?: "text" | "focus" | "prop" | "screen" | "background", chars?: { shown, total }, text?, words?, heading?, z?, allow?: kind[],
           native?: { width }, minTextPx?, anchor?: name, ground?: y, fontPx?, clip?: { x0, y0, x1, y1 }, opaque? }

kind = "pop" | "strobe" | "teleport" | "jump" | "spike" | "cropped" | "lost" | "untracked"
     | "offsafe" | "covers" | "overlap" | "unfinished" | "unread" | "empty" | "stale" | "legibility" | "anchor"
     | "clipped" | "blank" | "occupancy"

The cropped, lost and offsafe checks run when both width and height are given. The text rules see only samples with a role (under strict, untagged ones are props).

safeArea · boxOverlap · boxGap

safeArea(W, H, safe?): { top, right, bottom, left }     // px; 5% of the long side at its ends, 3.5% of the short side
boxOverlap(a, b): px²                                     // the area two boxes share
boxGap(a, b): px                                          // the distance between two boxes (0 when they touch)

inFrameShare

inFrameShare(box, W, H): 0..1     // the share of a box inside the frame

formatReport

formatReport(report, fps = 30): string

collectDom

collectDom(root = document.body): Record<name, Sample>     // every [data-romp] element, relative to root, with its box

Each sample also carries clip (what clipping ancestors leave of its box) and, on a text, fontPx (its smallest font-size × on-screen scale; data-romp-font-px overrides) and opaque (a solid background of its own; data-romp-opaque overrides). Only [data-romp] elements: an untagged element, or a prop drawn inside one <svg> or <canvas>, is invisible to the check.

untrackedOver

untrackedOver(root): { what, size, text, kind: "surface" | "text" }[]     // untracked surfaces and plain text over a tracked text or screen

What romp check --strict warns about (--untracked error: fails on): a drawing surface that isn't tracked and holds nothing tracked, after a shown text or screen in the document and overlapping it; or plain text with no tracked ancestor on a tracked text, or after and on a screen.

unionShare

unionShare(boxes, W, H, cells = 64): 0..1     // the share of the frame the boxes cover together

trackBurst

trackBurst(name, particles, { impact?, allowCrop?, allowExit? }): { "data-romp", …, style }

Props for an empty element covering a particle burst, centred where it comes from, at its strongest opacity: the motion check follows the burst as one object. Leave the particles themselves untracked.

A romp check entry default-exports a CheckEntry (or a function of --arg returning one): { component, props?, durationInFrames, fps, width, height, …any analyze() option }; spread a timeline's check into it.

romp/audio

Synth

The voices, on an (Offline)AudioContext, deterministic: marimba, bell, marker, rim, flap, whoosh, tap, splash, ignite, crackle, crickets, surf, wind, hum, birds, riser, thump, click, engine, reverb; set s.harmony = (t) => Set<pitchClass> to keep tonal effects in key.

createMix(synth, { levels?, sends?, room? }): { master, music, drums, sfx, voice }

playLive(audioContext, schedule, { from?, latency?: 0.08, extend? }): Promise<{ origin, stop() }>

soundKey

With cachedFile from romp/pipeline, an unchanged soundtrack is reused; romp sound --cache keys by the whole bundled module.

crossfadeBed

crossfadeBed(synth, out, { from, to, write(out, t0, t1), level? }[], { fade?: 0.5 }): joins

One continuous bed: each section's end is stretched to the next one's start, each is written fade / 2 past its joins, and an equal-power crossfade joins them.

dropouts · readWav · rmsWindows · formatDropouts

dropouts(audioBuffer | { sampleRate, channels }, { window?: 0.02, drop?: 30, floor?, min?: 0.1, max?: 1, around?: 0.25 }):
  { t, duration, level, bed }[]                 // seconds; dBFS (-120 is silence)
readWav(bytes): { sampleRate, channels: Float32Array[] }     // PCM 8/16/24/32-bit or float
rmsWindows(audio, window?): dBFS[]     formatDropouts(dropouts, file?): string

A dropout is a run of 0.1–1 s at least drop dB under the bed's median level, with sound on both sides. romp check --audio file.wav runs it.

A Schedule is (synth, buses, at) => void, where at(filmSeconds) is a context time, or null for something already played.

listen

listen(schedule, { extend? }): Score

Runs a (synchronous) schedule once against a silent stand-in for an AudioContext and records every voice it plays: the outermost call only, so an upright's pluck or a ding's marimba isn't counted twice. Runs anywhere: node, a worker, a Remotion render.

Score

score.events: { t, end, voice, bus, vel, midi?, shape: "hit" | "swell" | "bed", peakAt? }[]
score.select({ bus?, voice? }): ScoreEvent[]                   // a string or a list of strings each
score.onsetsBetween(t0, t1, filter?): ScoreEvent[]             // starts in [t0, t1)
score.envelopeAt(t, { bus?, voice?, decay? }): number          // sum of each event's level through its shape
score.beatAt(t, filter = { bus: "drums" }): { index, phase, since, t0, t1 }

Every method is a pure function of film time. A hit attacks in 5 ms then decays over its voice's ring (decay overrides it); a swell rises to peakAt and falls; a bed holds from t to end. beatAt uses the selected onsets as the grid (onsets within 30 ms count as one); index is −1 before the first.
